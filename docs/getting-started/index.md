# Getting started

These pages take you from a completed VASP calculation to a bonding plot and a
quality report. You need a working VASP setup to produce the input
calculation, but no prior experience with COHP or other bonding analyses.
A GPU is optional.

1. **[Key concepts](concepts.md)**: what PROWL does and how to read its
   results. Start here if COHP, ICOHP or charge spilling are new to you.
2. **[Install PROWL](installation.md)** into a Python environment.
3. **[Prepare the VASP inputs](vasp-inputs.md)**: the settings your
   calculation needs, with an example INCAR and a worked band count.
4. **[Run your first analysis](first-analysis.md)** with the supplied
   configuration, and learn to read the output.
