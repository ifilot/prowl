# Results, plots and export

Every `prowl run` writes a single result file, `bonding.h5`. It contains
everything about the analysis: the structure, orbital and bond labels, all
curves and integrated values, the quality diagnostics, the conventions used,
and a record of the settings and input files. Plots and exports are made from
this file, so you never need to rerun the analysis to make a new figure.

## Plot spectra

```bash
prowl plot ./vasp-run/bonding.h5 --kind cohp --bonds 0,1 --output cohp.png
prowl plot ./vasp-run/bonding.h5 --kind coop --bonds 0 --output coop.png
prowl plot ./vasp-run/bonding.h5 --kind pdos --bonds 0,1 --output pdos.png
```

`--bonds` takes a comma-separated list of indices, counted from **zero** in
the order of the bond table. For `--kind pdos` the indices refer to
**orbitals** instead of bonds. Without `--bonds`, the first six entries are
shown. `--emin` and `--emax` limit the displayed energy range (in eV).
Plotting needs Matplotlib (`python -m pip install matplotlib`).

:::{admonition} Sign conventions
:class: important

- **COHP** is stored with *negative = bonding*. Plots show **−COHP**, so
  bonding is to the right.
- **COOP** is stored and plotted with *positive = bonding*, so bonding is also
  to the right.
- In the CSV and HDF5 files, COHP values keep the stored sign (negative =
  bonding).
:::

The pDOS is given in the {term}`Löwdin-orthonormalized <Löwdin orthonormalization>`
basis. For spin-polarized calculations, the second spin channel is drawn
mirrored (to the left), as is customary.

## Export for other tools

Choose the format by what you want to do next:

| Format | Use it for |
| --- | --- |
| `csv` | Plotting in your own scripts, spreadsheets, or any other program |
| `json` | A compact summary: integrated values, diagnostics and settings, without the curves |
| `lobster` | Reusing scripts and tools written for LOBSTER output files |

```bash
prowl export ./vasp-run/bonding.h5 --format csv --output ./tables
prowl export ./vasp-run/bonding.h5 --format json --output ./summary
prowl export ./vasp-run/bonding.h5 --format lobster --output ./lobster-like
```

CSV export writes COHP, COOP and pDOS curves, integrated populations, shell-pair
ICOHP, and a JSON summary. Bond-frame results add channel-resolved tables.
JSON export writes `summary.json`, including integrated values, diagnostics and
provenance, rather than the full spectral arrays.

LOBSTER-format export writes COHP/COOP curves and integrated lists, charges,
and COBI files when available. The files are generated by PROWL. Their layout
supports existing readers, but basis, projection and window choices can differ
from a LOBSTER calculation. Exported running integrals of broadened curves can
also differ from occupation-weighted integrated lists.

## Inspect the HDF5 file in Python

```python
import json
import h5py

with h5py.File("./vasp-run/bonding.h5", "r") as f:
    labels = [x.decode() for x in f["analyses/cohp/bond_label"][()]]
    icohp = f["analyses/cohp/icohp"][()]  # (spin, bond)
    diagnostics = json.loads(f["reconstruction/diagnostics_json"][()])
    for label, value in zip(labels, icohp.sum(axis=0)):
        print(label, value)  # eV, summed over the stored spin channels
```

```{note}
**Spin channels.** For a non-spin-polarized calculation (`ISPIN = 1`) there is
one stored channel, and it already counts both spins: do not multiply it by
two. For a spin-polarized calculation (`ISPIN = 2`) there are two channels; add
them to get the total bond population, as the example above does.
```

The file is organized into groups:

| Group | Contents |
| --- | --- |
| `/meta` | Version, units, conventions, provenance and inspection JSON |
| `/structure` | Lattice, fractional positions, elements and valence counts |
| `/kpoints` | Coordinates, weights, mesh and spin factor |
| `/basis` | Orbital labels and atom/orbital offsets |
| `/reconstruction` | Diagnostics JSON, including the chosen window |
| `/analyses/cohp` | Energies, bond table, COHP and ICOHP; orbital/channel data |
| `/analyses/coop` | COOP and ICOOP |
| `/analyses/cobi` | COBI and ICOBI |
| `/analyses/pdos` | Orbital spectra and occupied integrals |
| `/analyses/charges` | Mulliken and Löwdin populations and atomic charges |
| `/projection` | Optional projected amplitudes and reuse key |
| `/performance` | Timings and backend |

The schema identifier is `prowl-bonding/1`. Bond spectral arrays have shape
`(spin, bond, energy)`; pDOS has shape `(spin, orbital, energy)`. Integrated
bond values have shape `(spin, bond)`. HDF5 bond atom indices are zero-based,
while human-readable labels use one-based atom numbers.

## Report a reproducible result

For a publication or thesis, record enough information for someone else to
repeat the analysis. Retain the PROWL version, VASP settings and potential identities, k-point mesh,
band count, basis source and shells, projection and window policy, bond selection,
and relevant quality diagnostics. The result stores many of these choices in
provenance. Keep the input configuration as well: the stored configuration is a
resolved flat record, while the YAML input uses nested sections.

Compare equivalent atom/image pairs and the same spin and normalization
conventions. Record why a basis or window was changed before interpreting a
difference as a chemical trend.
